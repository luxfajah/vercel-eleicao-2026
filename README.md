# 🚀 Deploy no Vercel — Apuração Presidencial 2026

Este projeto está 100% pronto para publicação no **Vercel** com suporte a:
1. **Frontend Interativo:** Mapa do Brasil em SVG com atualização automática a cada 1 segundo.
2. **Serverless Function (`api/tse.js`):** Consulta a API oficial do TSE em tempo real contornando restrições de CORS e com cache inteligente no Edge CDN da Vercel.

---

### Opção 1: Pelo Navegador (Sem instalar nada)

1. Acesse **[vercel.com/new](https://vercel.com/new)**
2. Crie uma conta ou faça login com GitHub/Google.
3. Se estiver usando o GitHub:
   * Crie um repositório no GitHub e envie os arquivos desta pasta.
   * No painel da Vercel, clique em **Import** no repositório.
4. Clique em **Deploy**.
5. Seu painel estará no ar com link público HTTPS instantaneamente!

---

### Opção 2: Pelo Terminal (com npx / CLI)

No terminal da sua máquina, execute:

```bash
npx vercel
```

Basta seguir as instruções na tela (pressionar Enter para confirmar os padrões) e a Vercel gerará o link oficial do seu site em segundos!
